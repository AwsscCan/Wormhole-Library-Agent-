## 二、闭环实现对照（责任包 §2）

| 责任包要求 | 实现 |
|---|---|
| append-only LearningEvent | `ledger.ts`：只追加不可变；查询强制 owner/session 过滤 |
| 带 confidence/evidenceCount/lastConfirmedAt/expiresAt 的推断 | `inference.ts`：跨 ≥2 会话的行为才成偏好；confidence = 0.35 + 0.2×(会话数−2)，上限 0.95；TTL 30 天 |
| 单次反馈不升格长期偏好 | feedback 事件被推断引擎完全排除（测试：单次 too_hard → 0 偏好） |
| 删除/遗忘后的索引失效 | `deleteMemorySnippet` / `forgetSession` 直接移出索引；账本保留但不可召回 |
| 词法+语义混合检索与小结果集重排 | `indexStore.ts`：0.6×词法 + 0.4×TF 余弦，按相关度+新近度重排；`mode:"lexical-only"` 供消融实验 |
| 有依据问答 | `qa.ts`：仅选定 snippet 可作证据；低于阈值或无支持 → `status:"unknown"`，明确拒答不编造 |
| MemoryReadPort 供包05 | `port.ts`：`getMemoryReadPort()` 未绑定为 null → 包05必须显式降级为无记忆推荐 |

## 五、技术文档总结段（可直接引用）

> 责任包 04 为 Wormhole Library Agent 引入了可审计的研究记忆层：所有用户研究行为（搜索、阅读、收藏、摘录、笔记、引用、反馈）以 append-only 事件账本的形式沉淀，偏好推断只在跨会话重复行为发生时提升置信度，且每条推断携带证据事件链、确认时间与过期时间，用户可随时撤销或按概念遗忘。私有检索采用词法与 TF 余弦的混合召回加小结果集重排，全程零 token、毫秒级，并以 owner 与会话双重作用域硬隔离，删除或遗忘的内容立即从索引失效且不可再次召回。资料问答严格限定在用户选定的私有材料内作答并给出摘录引用，无支持依据时明确返回"未知"而非编造。整个记忆层通过 `MemoryReadPort` 向推荐工作台（责任包 05）暴露只读端口，未接入时上游显式降级为无历史记忆推荐，保证了模块边界的可审计性与真实可部署性。
