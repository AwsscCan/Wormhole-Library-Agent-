# Wormhole Library Agent 十五分钟完整演示稿

## 演示定位

- **建议成片时长：** 14 分 30 秒至 15 分 30 秒。
- **演示载体：** 优先录制已安装的 Windows 应用，证明项目不是静态网页；最后再展示 Web 部署包和公开代码仓库。
- **演示主线：** 模糊目标 -> 联邦检索 -> 全量总结/初步综述 -> 虫洞与星图 -> 工作台与混合记忆 -> 证据写作 -> Living Library。
- **默认外观：** 全程使用“深夜纸墨”，主题切换环节短暂展示另外两种风格后切回。
- **录制原则：** 核心链路实际点击；次要功能扫过界面并口播点名。不要展示 API Key、Cookie、学校账号、私人文件或真实聊天内容。

## 录制前准备

1. 安装并启动 `Wormhole Library Agent 0.1.1`，确认任务栏、窗口、快捷方式均显示项目自己的“星轨与打开书本”图标。
2. 准备研究问题：`混合记忆如何提升研究型 AI Agent 的检索与写作质量？`
3. 准备一个不含隐私的 `demo-memory.md`，内容包含一条公式：`$R = \alpha S + \beta M$`。
4. 预先保留一个已有至少三条候选证据的研究会话，避免实时网络波动拖慢录制。
5. 如演示 Provider，只使用遮罩密钥；高校馆藏连接可填写示例地址但不要保存真实凭据。
6. 关闭通知、聊天软件和无关窗口；应用缩放保持 100%，分辨率建议 1920 x 1080。

## 0. 产品定位与桌面应用（0:00-0:30）

**画面：** 从桌面快捷方式启动应用，停留首页；让项目图标、窗口标题和完整首屏同时入镜。

**旁白：**

“这是 Wormhole Library Agent，一个把真实馆藏检索、知识星图、混合记忆、研究笔记和证据约束写作连成闭环的个人研究工作区。现在展示的是安装在 Windows 上的实际应用，不依赖源码目录或开发服务器。接下来我会从一句模糊目标开始，完整走一遍可恢复的研究流程。”

## 1. 导航、访客身份与账户系统（0:30-1:10）

**操作：** 鼠标快速扫过顶部七个入口：探索台、研究工作区、记忆核心、写作工作台、研究笔记、活馆藏、模型设置。点击右上角“访客身份”，在账户页切换“登录/注册”，然后返回首页。

**旁白：**

“顶部导航覆盖七个工作区域，探索台与研究工作区使用不同图标。首次打开会自动建立签名访客身份，不登录也能保存私有会话；账户页同时支持邮箱密码注册、登录和退出，密码至少十位，本期不要求邮箱验证。登录后，研究会话、笔记、证据、Provider 和写作检查点都按账户隔离。”

## 2. AI 全量搜索与直接检索（1:10-2:30）

**操作：** 回到首页，输入演示问题。依次点过任务类型“课程、项目、研究、考试、好奇”和水平“初学、本科、研究生、研究者”，最后选择“研究 + 研究者”。展示“AI 全量搜索/直接检索”切换、三个输出选项和意外度滑块，选择“AI 全量搜索 + 初步综述”，点击开始。

**旁白：**

“探索台接受自然语言目标。任务类型和知识水平会影响检索计划与表达深度。AI 全量搜索会先把目标拆成多个检索意图，再扫描联邦来源；直接检索则用一个明确关键词快速进入结果页。AI 模式可以生成全量总结、资料概要或初步综述。默认强调准确性，意外度只控制主动发散；直接检索也可以勾选‘搜索后继续发散探索’。下方还有三个一键预设信号，适合快速体验。”

**画面证据：** 保留加载文案“AI 正在拆解目标并检索”，随后展示实际查询路径。

## 3. 多来源结果、总结与初步综述（2:30-3:30）

**操作：** 展示 AI 拆出的多个查询、已扫描总数、相关性初选数、来源标签和结果列表；打开一条原始来源，再返回应用。快速扫过生成正文和“查看星图/已存笔记”入口。

**旁白：**

“Agent 不只是把问题原样交给搜索框，而是生成多条有用途说明的查询，再合并 OpenAlex 论文、Open Library 图书、个人馆藏和本地离线种子，完成去重与相关性排序。同一记录命中多个来源时会保留组合来源。每条外部结果都能打开原始页面；上游超时、空结果或需要权限时会明确标记降级，不把失败伪装成没有文献。这里的正文是对全部候选的速览或初步综述，正式引用仍要求回到原文核验。”

## 4. 会话虫洞与反馈学习（3:30-4:25）

**操作：** 用一个已保存的直接检索会话进入探索详情。展示候选总数、来源数量、“加载更多”、意外度滑块；点击“生成并保存虫洞”，展示概念路径和落点馆藏。随后打开兼容探索视图，扫过完整评分与反馈区。

**旁白：**

“直接检索结果会写入研究会话，因此刷新或服务重启后仍能恢复。结果按相关性排序并支持分批加载。PaperWorm 虫洞根据起点概念和意外度寻找跨概念桥梁，展示起点、桥接概念、目标、解释和落点资源。兼容探索视图中的完整虫洞卡还提供新颖度、桥接度、质量分和综合分，并支持‘有用、刚刚好、太熟、跳太远、太难、不相关’六类反馈和补充文字；反馈先进入事件账本，再由记忆编译器更新偏好。”

## 5. Knowledge Atlas 与 Open Library 星图（4:25-5:25）

**操作：** 回到首页右侧 Knowledge Atlas。先在“知识星区”点击一个节点自动填入搜索框；再切换“馆藏分类”，点击“计算机科学 -> Artificial intelligence -> 一条书目”，打开 Open Library 来源并返回上一级。

**旁白：**

“首页星图有两种模式。知识星区会根据输入点亮概念，点击节点可直接成为搜索主题；馆藏分类连接 Open Library 实时分类，父星与子分类、书目通过关系线连接。点击分类会进入子星图，支持继续下钻、路径返回和分类搜索；点击书目则打开真实 Open Library 页面，所以星图既是导航，也是馆藏入口。”

## 6. 研究会话与每日推荐（5:25-6:20）

**操作：** 打开研究工作区。展示“研究问题 + 可选写作主题”的新建表单、最近工作区的版本/检索数/证据数/更新时间、刷新和删除按钮；滚动到今日推荐并打开一条来源。

**旁白：**

“研究工作区把搜索、虫洞、证据、个人星图和写作工件绑定到持久化会话。可以单独填写研究问题和写作主题，刷新列表，或删除整条记录；删除前会确认，并级联清理星图、证据篮、工作台和写作工件。每日推荐默认以低意外度从公共学术来源和个人历史生成四条结果，显示来源、与已有知识的关系、缓存或降级状态，并可继续进入推荐工作台。”

## 7. 个人星图与混合记忆图层（6:20-7:30）

**操作：** 打开一个会话地图。切换“我的星图/馆藏总图”，打开记忆图层，拖动知识距离；点击节点，修改标签和注释，固定、隐藏再恢复；连一条个人关系并删除。最后点“查看主题馆藏”或“加入证据篮”。

**旁白：**

“会话地图保持统一的 Knowledge Atlas 视觉语言。我的星图综合主题、搜索结果、推荐投影、写作与上传活动；搜索越频繁，节点越亮，知识距离滑块改变节点间距。混合记忆图层把当前 RAG 命中和长期偏好叠加到星图，并解释记忆为何影响某个节点。用户可以拖动、改名、写注释、固定、隐藏和恢复节点，也能新增个人连线、隐藏系统边或删除个人边。节点还可以继续搜索、查看主题馆藏、选为证据，并从星图回到工作台的笔记或草稿。”

## 8. 阅读、概念、证据三视图工作台（7:30-8:40）

**操作：** 点击“打开推荐工作台”。切换低/中/高每日推荐意外度并生成；依次快速展示“阅读计划、概念图、证据与草稿”三个标签页。

**旁白：**

“探索工作台把推荐转成可执行研究。每日推荐支持低、中、高三档发散比例，并显示来源状态、使用了多少条 RAG 片段和长期偏好。阅读视图可设置目标、预计时长、完成定义和下一步，资源可加入计划、排序、移除、标记完成、添加标签和私有笔记，也能继续搜索并反馈有用、太远或太难。概念视图允许新增个人概念边。证据视图可以新增主张，把资源标成支持、反驳、背景或待核验，再保存带来源反链的段落；每段最多选择五十条证据，但馆藏总量不限。所有用户层更改都带版本保存，多窗口冲突会要求刷新。”

## 9. 混合记忆与私有 RAG（8:40-9:35）

**操作：** 打开记忆核心，在 RAG 搜索框输入“混合记忆”，展示命中条目、分数和命中方式；扫过下方仪表和更新流水，不执行重置。

**旁白：**

“记忆核心把三类数据分开可视化：搜索、阅读和反馈形成行为事件；笔记、摘录和写作形成 RAG 片段；跨会话重复行为才编译为长期偏好。私有 RAG 会显示每条命中的来源 ID、会话、相关分数，以及词法、语义或两者共同命中。配置 Ollama 时使用真实向量嵌入，不可用时明确显示本地字符语义降级。下方还能看到意外度、难度、语言与资源类型、概览优先、社交匹配和更新流水；‘重置我的记忆’只在需要时主动执行。”

## 10. Markdown、LaTeX 研究笔记（9:35-10:15）

**操作：** 打开研究笔记，新建标题，输入一段 Markdown、HTTP 链接、行内公式和展示公式，展示实时预览后保存；点一下已有笔记的版本号和删除按钮但取消删除。

**旁白：**

“研究笔记按当前身份隔离，支持新建、编辑、保存、版本号、重新载入和删除。编辑区支持标题、列表、安全外链、行内与块级 LaTeX，并用 KaTeX 实时预览；原始 HTML 和脚本不会执行，非法链接也不会被打开。保存后的笔记会成为私有知识记录，并可供后续知识整理使用。”

## 11. 写作模板、上传与证据篮（10:15-11:25）

**操作：** 打开写作工作台，展示会话选择、删除记录、三个模板分类和搜索框。快速扫过模板卡；选择“证据约束章节”。上传 `demo-memory.md`，分别点过“临时资料 30 天/私有知识库”，勾选文件；点击“发现候选”，打开来源并确认至少三条证据。

**旁白：**

“写作台只负责证据约束写作；全量总结和文献综述入口留在探索台。这里提供研究发现、学术写作、已有资料三类共十五个可见工作流，包括证据章节、Idea 发现、自动审稿、实验桥接、全流程、论文写作、中文论文、Nature 结构、开题、课程论文与报告、一句话项目、已有资产到论文、软著材料和专利交底。卡片会标明当前引擎可运行，或以证据写作降级运行，复杂代码、图表、PDF、DOCX 不会伪装成已生成。

资料支持 TXT、Markdown、CSV、JSON、BibTeX、PDF、DOCX，单个不超过 25 MB。用户可选择临时保存三十天或长期进入私有知识库，并随时勾选或删除。候选文献来自联邦检索，必须打开来源并人工确认，至少三条已确认证据才能运行。”

## 12. 生成、检查点、回链与导出（11:25-12:25）

**操作：** 快速展示输出语言、模型、引用格式、语气、检查点、改进循环、步骤模型和自定义要求。运行工作流；展示日志、左右编辑/预览、保存、重跑、通过检查点、证据回链、人工复核和导出按钮。

**旁白：**

“每次运行可选择跟随材料、中文或英文，选择账户模型预设，使用证据标记、APA 或国标引用，并设置学术、简洁或解释型语气。还可以启用人工检查点、改进循环、单独指定初稿模型和填写格式约束。运行步骤包括任务、材料、证据、提纲、初稿、人工复核和产物，右侧日志显示真实状态。左边编辑 Markdown，右边实时预览；可以保存修改或重跑当前步骤。只有依次完成检查点、证据回链和人工复核后，才能导出 Markdown。没有可用模型时会生成明确标识的本地可追溯草稿，而不是冒充模型输出。”

## 13. 主题、语言、模型与馆藏来源设置（12:25-13:35）

**操作：** 打开模型设置。依次点击“山水墨卷、抽象构成、深夜纸墨”；切换检索语言；展示 CC Switch 的 Claude/Codex 标签、DeepSeek 快速配置、Provider 表单、当前账户列表和模型预设。进入馆藏来源页，展开协议下拉并返回。

**旁白：**

“设置中心统一管理外观、语言、模型和馆藏入口。三种完整界面风格是深夜纸墨、山水墨卷和抽象构成，选择会立即跨页面生效并持久保留；检索语言支持不偏好、中文优先和英文优先。CC Switch 只读取本机脱敏目录，按 Claude 或 Codex 显式勾选导入，不暗中改配置。

Provider 支持 DeepSeek 快速配置，以及 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 三类协议；可设置名称、HTTPS 地址、模型和密钥，并完成保存、编辑、测试连接、清除密钥和删除。密钥只在服务端加密保存，列表只显示是否已配置。模型预设还可控制温度与最大 Token，并在写作工作流复用。

普通用户无需改代码即可新增个人馆藏源，支持 Koha/Alma REST、SRU/OPAC、OAI-PMH、Z39.50 和 MARC/CSV/JSON 导入端点，还可配置地址、可选凭据和字段映射，并测试、查看可访问或需要权限状态、删除来源。系统不会绕过学校 SSO、校园网、IP 白名单或付费墙。”

## 14. Living Library 双向同意与 AI 馆员（13:35-14:35）

**操作：** 打开活馆藏。勾选自己的专长和交流方式，展示匿名登记/暂停；选择“Wormhole AI 馆员”，选交流主题并提问。展示自动接受和回答，再扫过消息、分享书目、分享私有资料、撤销授权入口。

**旁白：**

“Living Library 把愿意分享经验的人作为可发现馆藏。用户可以选择 AI Agent、信息检索、知识管理、多智能体、认知心理学等专长，以及文字答疑、十五分钟交流或领读入门，并随时匿名登记、更新、暂停或注销。真实活书请求默认等待对方接受，也可以拒绝；双方同意前不能继续聊天或共享资料。

Wormhole AI 馆员是明确标识的演示活书，会自动接受并答疑：配置模型时结合对话、已共享来源和当前用户私有 RAG，没有模型时使用可追溯的本地回答。会话建立后支持持续消息、共享 HTTP/HTTPS 书目链接、按授权共享私有资料，并由分享者随时撤销资料授权。”

## 15. 持久化、安装包与开源交付（14:35-15:00）

**画面：** 快速切换到应用数据恢复后的研究会话；展示安装包文件名、README、项目简介、演示稿和仓库首页。

**旁白：**

“所有核心流程都由 SQLite、Prisma 和账户身份持久化，刷新或重启后仍能恢复。Windows 安装包首次启动会在用户目录初始化数据库和随机密钥，端口占用时自动选择可用端口，异常会给出日志路径。项目同时提供 Next standalone Web 包、完整源码、README、部署说明、项目简介和演示材料。以上就是 Wormhole Library Agent：让一次搜索成为可追溯、可积累、可继续写作的个人研究系统。”

**结尾字幕：**

`Wormhole Library Agent · Search, connect, remember, write.`

## 剪辑与风险提示

- 实时检索等待超过 8 秒时，可加速等待段，但保留开始操作和真实结果，不剪成伪造瞬时响应。
- OpenAlex 或 Open Library 不可用时，直接展示“显式降级/本地种子”状态并解释，不重录成假在线结果。
- 写作模板只展示系统明确标注的当前能力；不要声称已经生成尚未接入的复杂代码、图表、PDF 或 DOCX。
- 文献综述在探索台演示，写作台不再作为独立综述入口。
- 主题切换最后必须回到默认“深夜纸墨”。
- Provider、学校馆藏和 Living Library 均不展示真实凭据、私人资料或第三方身份。
- 结尾仓库地址使用实际公开地址：`https://github.com/AwsscCan/Wormhole-Library-Agent-`。
