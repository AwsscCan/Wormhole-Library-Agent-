# Wormhole Library Agent 项目简介

## 一句话定位

Wormhole Library Agent 是一个面向个人研究者、学生和知识工作者的可恢复知识管理工作区：用户给出一个研究目标，系统联邦检索 OpenAlex、Open Library 以及用户配置的馆藏源，按相关性整理结果，以 Knowledge Atlas 星图呈现知识关系，并把可核验资料带入私有记忆、笔记和证据约束写作流程。

## 解决的问题

研究资料通常分散在论文索引、图书馆目录、本地文件和个人笔记中。用户需要反复切换工具、手工判断来源、重新组织上下文，搜索结果也很难沉淀为下一次可用的知识。本项目把“目标拆解、联邦检索、来源核验、知识组织、记忆召回、写作复核”连接成一条持久化链路，并在外部服务不可用时明确展示降级状态。

## 目标用户与场景

- 学生和研究者：从模糊课题开始寻找论文、图书、方法和研究空白。
- 需要维护个人知识库的知识工作者：把笔记、附件、检索结果和阅读反馈集中保存。
- 需要高可追溯文本的写作者：从确认过的证据生成带引用标记、可人工复核的 Markdown 草稿。
- 有高校或机构馆藏权限的用户：在设置中接入合法的公开 OPAC、机构 API 或导出的 MARC/CSV/JSON 馆藏数据。

## 核心功能

### 1. AI 全量搜索

首页支持直接检索和目标驱动搜索两种路径。目标驱动路径会将模糊目标拆解为多个查询意图，联合检索已启用来源，去重并按相关性排序。结果区展示实际查询路径、候选总数、初选数量、来源分布和可打开的原始链接，并基于全部候选的题名、作者、来源和可用摘要线索生成可追溯总结。搜索默认强调准确性；意外度滑块仅用于用户主动发散或每日推荐式探索，不替代准确检索。

系统不会把元数据总结冒充全文阅读。没有可用模型时，仍返回确定性的本地总结，并标明其边界。

### 2. 真实馆藏与 Knowledge Atlas

Open Library 分类星图从实时接口读取分类、子分类和书目，根星与子星通过连线表达层级关系，点击子星可递归下钻，点击书目可打开 Open Library 原始页面。研究工作区的“馆藏总图”复用同一视觉和交互语言；个人星图则投影当前会话、搜索结果、资源、记忆和推荐之间的关系。

星图支持个人知识层编辑、关系删除、节点隐藏/恢复、知识距离调节和记忆图层。节点亮度与搜索频次、记忆权重和当前命中相关；记忆层使用铜色标记，与知识关系和馆藏来源区分。馆藏状态和来源 provenance 会以真实状态呈现，不可访问的高校网络、SSO 或付费全文不会被伪装成已接入。

### 3. 混合记忆与私有 RAG

检索会结合当前会话、长期偏好、反馈事件、笔记和已上传资料。记忆是 owner-scoped 的，写入由服务端当前主体和已授权研究会话推导，不信任浏览器传入的 owner。可用 Ollama 嵌入模型时使用真实向量检索；Ollama 不可用时明确显示词法降级，不宣称语义召回。记忆快照自动恢复和持久化，写入边界使用深拷贝，避免调用方修改历史账本。

### 4. 写作工作台

文献综述和资料总结属于探索台的全量结果，不在写作台重复列为模板。写作台负责将探索台或研究会话中确认的证据带入证据约束写作：上传 Markdown、PDF、文本等材料时可以选择只用于当前工作流，或进入个人知识库；临时资料默认保留 30 天，进入知识库的资料按知识库生命周期保存。

工作流包含任务配置、材料、证据篮、提纲、初稿、证据回链、人工复核和导出。每条候选来源有 provenance 和状态，用户必须人工确认来源后才能进入生成上下文。生成支持模型配置、语言、引用格式、语气、检查点和重跑；编辑器左侧可修改 Markdown，右侧实时预览，生成后的引用可回到证据记录核验。

### 5. 模型与个人馆藏设置

设置中心统一提供 Provider、模型预设、主题、语言和馆藏源入口。支持 OpenAI 兼容接口、DeepSeek 配置和 CC Switch 的显式脱敏预设导入；密钥只在服务端加密保存。普通用户可添加自己有权访问的馆藏地址或导入馆藏文件，无需修改代码；高校资源若要求校园网、SSO、IP 白名单或订阅权限，仍需用户/机构自行完成授权。

默认外观是“深夜纸墨”，同时保留可持久化的其他视觉方案。设置会跨页面保存，研究星图、馆藏星图、笔记和写作工作台共享同一套主题变量。

### 6. Living Library

Living Library 采用同意优先的交流模型：用户可以选择自己擅长的主题和希望交流的主题，向匿名馆藏发起申请；双方同意后进入私密对话，可在对话中共享明确选择的馆藏记录或知识资产。AI 馆藏作为演示用的必定同意对象提供答疑入口，但不会暴露真实用户身份、私有凭据或未授权文件。

## 技术方案

- 前端：Next.js 15 App Router、React 19、TypeScript、Tailwind CSS、Lucide、Framer Motion。
- 知识交互：React Flow；Knowledge Atlas 以稳定节点/边模型表达层级、内容关联、个人覆盖层和记忆投影。
- 服务端与存储：Next.js Route Handlers、Prisma、SQLite、版本化迁移、Better Auth。
- 检索：联邦馆藏端口；OpenAlex、Open Library、种子/导入源和用户配置源均保留来源状态与 provenance。
- 记忆：owner-scoped 事件账本、自动快照、混合词法/向量召回；Ollama `/api/embed` 是可选的真实向量提供方。
- 写作：证据确认、来源回链、模型预设解析、检查点、人工复核和 Markdown 导出。
- 交付：Next standalone Web 包与包含 standalone 服务的 Electron Windows 安装包。

## 使用方式与入口

本地启动：

```powershell
npm install
Copy-Item .env.example .env.local
npm run db:deploy
npm run db:seed
npm run dev
```

访问 `http://localhost:3000`。常用入口为 `/research`、`/writing`、`/notes`、`/memory`、`/living-library`、`/settings/providers` 和 `/auth`。

Web 包：`npm run package:web`，产物为 `dist/Wormhole-Library-Agent-Web.zip`。

Windows 安装包：`npm run package:desktop`，产物目录为 `dist/desktop/`。

## 边界与合规说明

本项目只读取用户有权访问的目录、接口和文件。高校 SSO、校园网 IP 白名单、代理、订阅数据库、付费墙和全文下载权限不能由应用绕过；应用会将这类情况显示为需要授权或不可用。AI 生成内容始终要求人工核验来源，不替代学术判断。
