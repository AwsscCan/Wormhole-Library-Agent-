### F-002：append-only 账本不具备 P04 承诺的不可变性

- severity: blocker
- evidence_ids: [E-002]
- impact: 历史事件的来源信息可在写入后被调用者修改，偏好推断的证据链不可审计。

### E-003：默认检索并未提供可靠的同义语义能力

- source_ref: `ba17b4a:lib/research/memory/embedding.ts`; `ba17b4a:tests/unit/memory-semantic-ablation.test.ts`
- repro_command: 默认 embedding 下以 `car servicing` 查询 `automobile maintenance`；对比测试中的 injected `synonymEmbedding`。
- evidence: 默认路径是字符 n-gram 哈希。完整无词面同义的成功只来自测试手写注入向量；可选 `ollamaEmbedding()` 异步返回，而现有 index API 是同步 `EmbedFn`，不能直接成为默认生产实现。

### F-003：P04 默认混合检索不满足语义检索责任

- severity: blocker
- evidence_ids: [E-003]
- impact: 不能把字符相似或哈希碰撞当作稳定同义理解；实际用户的无词面重叠研究问题没有可靠召回保证。
- remediation: P04 选择并接入可实际运行的向量语义 provider（本地模型或受控远端），将索引 API 改为 async 并提供明确降级；补无 token-overlap 的中英文同义回归测试，不能依赖测试专用手写 embedding。

### E-004：P04 快照只有手动 API，且恢复后 ID 递增错误
